## Visual language and animation rules
- 16:9, 1920 × 1080, 30 fps; exactly 5,400 frames. Export H.264 MP4 with AAC audio, plus captions.
- Cool white and neutral grey, dark type, one restrained blue accent. Retain the real products' visual identities.
- Use a small original pixel time-machine car as a transition cue three times. No film footage, logo or borrowed movie music required.
- Carry a recurring visual motif through the edit: the page becomes an answer, which opens into a contribution with its context.
- Animate grouping, focus, expansion and travel. Never animate a nonexistent UI action as though it were implemented.
- Crop real UI to the relevant region. Essential text should be legible on a phone; aim for 32px or larger at 1080p.
- Keep cursor movement deliberate. Remove typing delays and loading waits with clean cuts; mark accelerated sequences if their timing matters.
- Use one principal thought per shot. No wall of architecture boxes; technical internals remain outside the main cut.
- Readable burned-in captions or a captioned delivery version, plus an SRT file. Captions follow the final recorded voice, not guessed timings.
- Quiet original/licensed music optional; narration remains intelligible. A subtle transition sound is enough for the car.

## What to omit from the three-minute cut
- Full PDF history, byte/object tutorial and multiple cabinet experiments.
- Architecture inventory, raw schemas and backend setup commands.
- Full isolated-PDS publication/rebuild sequence: useful backup material, too much for the core cut.
- Graph decoration, invented usage counts, fabricated testimonials or “verified human” badges.
- Observatory feature tour, service installation, CI or merge history.

## Truthful fallbacks
- A UI clip is blocked: use an actual screenshot with a focus animation and label it as a recorded prototype view. Do not simulate a successful submission.
- CLI/MCP capture is unavailable: show real repository/search rediscovery. The narration lists possible entrances; do not draw a fake live agent exchange.
- C is not delivered: use the existing Observatory concept/source inspector; omit the implementation-record action.
- Live network is unavailable: use captured clips offline. This is an edited demonstration video; a live network is not required for playback.
- Never imply current public federation, proof of humanity, an interoperable .phf file standard or proven community adoption.

## Acceptance for the final deliverable
- Exactly 03:00 including end hold; inspect the actual exported duration.
- All three parts are clear, .phf receives 115 seconds and the contribution-to-rediscovery payoff is visible.
- Every demo clip has a known source revision and every staged input is labelled.
