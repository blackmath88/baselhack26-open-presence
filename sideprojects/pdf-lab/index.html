06 / PRESERVATION CHANGES THE WORK

Print me to ruin
the puzzle.

On screen, a maze. In print mode, its solution. A print-only annotation turns the same file into a different experience.

Open the print trap ↗
Reveal the mechanism

The route is an annotation with Print + NoView flags. Both renderings shown here come from Ghostscript 10.02.1 with its actual screen/print settings.

gs -dPrinted=false ... document.pdf
gs -dPrinted=true  ... document.pdf

Physical printing and other viewers' print modes remain untested. The solution was always in the file; hiding from view is not erasure.
