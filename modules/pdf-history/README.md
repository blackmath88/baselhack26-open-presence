## Narrative in one sentence

Follow one document from unreliable exchange, through a portable page representation and the economics of receiving it, to the question of what should travel with an AI-mediated answer.

## Working visual direction

Explore early Acrobat / 1990s–early-2000s document UI: title bars, menus, font substitution, print dialogs, file associations, installer/read dialogs and page thumbnails. The user explicitly wants the quirks of that era to do explanatory work. Edition 01 uses an original document-workbench interpretation. It is a working direction, not a historical reconstruction or the result of the three proposed visual studies. The user's subsequent request authorised building this first version.
