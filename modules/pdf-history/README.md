# PDF history — It looked fine on my computer.

Planning module · 31 October 2026 · Working title, not a project rename

**Explain what PDF made portable, why that mattered, and how making documents easy to receive created business value.**

This is an optional historical explainer within Open Presence. It must stand alone as a history of PDF and can end with a short bridge to the contribution/context experiment. The Photo Frame Commons pilot remains the main project. This module has no dependency on Knowledge Lab, live ATProto, inference or federation.

## Narrative in one sentence

Follow one document from unreliable exchange, through a portable page representation and the economics of receiving it, to the question of what should travel with an AI-mediated answer.

## Visual direction remains open

Explore early Acrobat / 1990s–early-2000s document UI: title bars, menus, font substitution, print dialogs, file associations, installer/read dialogs and page thumbnails. The user explicitly wants the quirks of that era to do explanatory work. The suggested 1998 desktop shell is a study candidate, not an approved design or historical reconstruction.
